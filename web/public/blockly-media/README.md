# Blockly media

`sprites.png` (trashcan and zoom controls) and the three drag cursors, copied unchanged from
`node_modules/blockly/media/` of the pinned `blockly@12.5.1` (Apache-2.0, © Google LLC / Raspberry
Pi Foundation). The Station program editor sets `media: "/blockly-media/"` so Blockly never loads
them from its default CDN. Update them together with the `blockly` version.
